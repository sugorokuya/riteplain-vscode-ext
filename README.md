# RitePlain VS Code Extension

このディレクトリには、軽量マークアップ言語RitePlain(ライトプレーン)のVisual Studio Code拡張機能が含まれています。

## 概要

RitePlain拡張機能は、すごろくやのソーシャルメディア統合型ボードゲームECサイト「SUPPE」でのプレイズ執筆にあたり、Visual Studio Codeを使用してRitePlain形式で記事内容を効率的に作成できるようにするためのものです。

主な機能：
- RitePlain構文のシンタックスハイライト
- スニペットによる一般的なRitePlain要素の挿入
- 太字、見出し、リスト、リンクなどの書式コマンド
- キーボードショートカット

## インストール方法

1. `cd vscode-extension/riteplain`で拡張機能のディレクトリに移動
2. `npm install`で依存関係をインストール
3. `npm run package`でVSIX拡張機能パッケージを生成
4. VSIXファイルをVS Codeにインストール

詳細なパッケージングとインストールの手順については、`riteplain/PACKAGING.md`を参照してください。

## RitePlain書式ガイド

以下はRitePlain（プレイズ形式）の基本的な書式です：

### 見出し
```
# 見出しレベル1
## 見出しレベル2
### 見出しレベル3
```

### 強調（太字）
```
[[重要なテキスト]]
```

### 階層リスト
```
* 箇条書き項目
** ネストされた箇条書き項目
*** 更にネストされた項目

. 番号付きリスト項目
.. ネストされた番号付き項目
```

### リンク
```
link:https://example.com
link:https://example.com[リンクテキスト]
```

### 画像
```
image::slot-1
image::slot-1[キャプション]
image::slot-1[キャプション, size=small]
```

### 補足枠
```
|注意：これは補足情報です。
```

### その他
- 水平線：`---`
- コメント：`// コメントテキスト`
- 行継続：行末の`+`で次行と連結

プレイズ書式の詳細については、ファイル ./rite_plain_format.md を参照してください。
